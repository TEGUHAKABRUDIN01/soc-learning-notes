# Computer Network Fundamentals

## Overview

A computer network is a collection of devices, such as computers, smartphones, printers, and servers, that are connected through communication media to exchange data and share resources.

Networks enable devices to communicate efficiently, access shared services, and exchange information.

---

## Types of Computer Networks

### 1. PAN (Personal Area Network)

A Personal Area Network (PAN) is a small network used to connect personal devices over a short distance.

**Examples:**

- Smartphone and Bluetooth headset
- Smartphone and smartwatch
- Laptop and wireless mouse

---

### 2. LAN (Local Area Network)

A Local Area Network (LAN) connects devices within a limited geographic area such as a home, school, or office.

**Characteristics:**

- High-speed communication
- Privately managed
- Low latency

**Examples:**

- Home Wi-Fi network
- Office network
- School computer laboratory

---

### 3. MAN (Metropolitan Area Network)

A Metropolitan Area Network (MAN) connects multiple LANs across a city or metropolitan area.

**Examples:**

- University campuses
- Government offices within a city
- Internet service provider infrastructure

---

### 4. WAN (Wide Area Network)

A Wide Area Network (WAN) connects networks over large geographic areas such as countries or continents.

The Internet is the largest example of a WAN.

**Examples:**

- Company branch offices in different cities
- International corporate networks
- The Internet

---

## Main Components of a Network

### 1. Network Devices

Hardware that enables communication between devices.

**Examples:**

- Router
- Switch
- Hub
- Computer
- Server
- Access Point

---

### 2. Transmission Media

The physical or wireless medium used to transmit data.

**Wired Media**

- Ethernet (UTP)
- Fiber Optic
- Coaxial Cable

**Wireless Media**

- Wi-Fi
- Bluetooth
- Cellular Network

---

### 3. Network Protocols

Protocols define the rules that allow devices to communicate over a network.

**Examples:**

| Protocol | Purpose                         |
| -------- | ------------------------------- |
| TCP      | Reliable data transmission      |
| UDP      | Fast data transmission          |
| DHCP     | Automatic IP address assignment |
| DNS      | Domain name resolution          |
| HTTP     | Web communication               |
| HTTPS    | Secure web communication        |
| FTP      | File transfer                   |
| SSH      | Secure remote access            |

---

## Network Topologies

A network topology describes how devices are physically or logically connected.

Common topologies include:

- Bus
- Star
- Ring
- Mesh
- Tree

The **Star Topology** is the most common in modern LANs because it is easy to manage and troubleshoot.
