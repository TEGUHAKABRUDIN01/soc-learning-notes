# Windows Security

## Overview

Windows Security is the built-in security application in Microsoft Windows designed to protect users from various cybersecurity threats. It provides essential security features such as antivirus protection, firewall management, application security, and device protection.

Because Windows is the most widely used desktop operating system in the world, it is a common target for cyberattacks. Windows Security helps reduce these risks by providing multiple layers of protection.

---

## Main Areas of Windows Security

### 1. Virus & Threat Protection

Provides protection against malware, viruses, ransomware, spyware, and other malicious software.

**Features:**

- Microsoft Defender Antivirus
- Quick Scan
- Full Scan
- Custom Scan
- Protection History

---

### 2. Firewall & Network Protection

Manages the Windows Defender Firewall to help block unauthorized network traffic entering or leaving the computer.

**Features:**

- Domain Network
- Private Network
- Public Network
- Allow an app through the firewall
- Advanced Firewall Settings

---

### 3. App & Browser Control

Protects the system from untrusted applications, malicious websites, and phishing attacks.

**Features:**

- SmartScreen
- Reputation-based Protection
- Exploit Protection
- Potentially Unwanted App (PUA) Protection

---

### 4. Device Security

Provides hardware-based security features that help protect the operating system and sensitive data.

**Features:**

- Core Isolation
- Memory Integrity
- Security Processor (TPM)
- Secure Boot

---

## Summary

| Area | Purpose |
|------|---------|
| **Virus & Threat Protection** | Detects and removes malware and other threats. |
| **Firewall & Network Protection** | Monitors and filters network traffic to protect the computer. |
| **App & Browser Control** | Protects against untrusted applications, malicious websites, and phishing attacks. |
| **Device Security** | Uses hardware security features to help protect the operating system and user data. |
