# Windows OS Structure

## Overview

Windows organizes files and directories into several main folders. Each folder has a specific purpose, such as storing operating system files, installed applications, user data, and system configurations. Understanding these folders is important for system administration and security investigations.

## Types of Windows OS Structure

### 1. C:\

The root directory of the Windows operating system. It serves as the main location that contains important system folders such as `Windows`, `Program Files`, `Users`, and `ProgramData`.

**Common Contents:**

- Windows
- Program Files
- Program Files (x86)
- Users
- ProgramData
- PerfLogs

---

### 2. C:\Windows

Contains the core files required for the Windows operating system to function.

**Common Contents:**

- `System32` – Core system files, DLLs, and Windows utilities.
- `Temp` – Temporary files created by Windows.
- `Logs` – System log files.
- `WinSxS` – Windows component store.

> **SOC Analyst Note:** This folder is frequently examined during malware analysis and incident response because attackers may abuse system files or create persistence within Windows directories.

---

### 3. C:\Program Files

The default installation directory for **64-bit applications** on a 64-bit Windows operating system.

**Examples:**

- Google Chrome
- Microsoft Office
- Wireshark
- Visual Studio Code

> **SOC Analyst Note:** Useful for identifying installed software during an investigation.

---

### 4. C:\Program Files (x86)

The default installation directory for **32-bit applications** on a 64-bit Windows operating system.

**Examples:**

- Legacy applications
- Older software that only supports 32-bit architecture

> **SOC Analyst Note:** Attackers may also install malicious software in this directory to appear legitimate.

---

### 5. C:\Users

Stores user profiles and personal data for each Windows account.

**Common Contents:**

- Desktop
- Documents
- Downloads
- Pictures
- AppData

> **SOC Analyst Note:** This is one of the most important folders during investigations because malware often stores files inside user profile directories, especially within `AppData`.

---

### 6. C:\ProgramData

Stores application data that is shared across all users on the computer.

**Characteristics:**

- Hidden by default
- Contains application settings and configuration files

> **SOC Analyst Note:** Frequently checked for persistence mechanisms and application artifacts.

---

### 7. C:\PerfLogs

Stores performance logs generated by Windows performance monitoring tools.

> **SOC Analyst Note:** Rarely used during routine investigations but may provide useful performance-related information.

---

## Summary

| Folder | Purpose |
|---------|---------|
| `C:\` | Root directory containing all major system folders. |
| `C:\Windows` | Windows operating system files. |
| `C:\Program Files` | Installed 64-bit applications. |
| `C:\Program Files (x86)` | Installed 32-bit applications. |
| `C:\Users` | User profiles and personal files. |
| `C:\ProgramData` | Shared application data and configuration. |
| `C:\PerfLogs` | Windows performance logs. |

## Key Takeaways for SOC Analysts

- `C:\Windows` contains critical operating system files.
- `C:\Users` is a common location for user activity and malware artifacts.
- `Program Files` and `Program Files (x86)` help identify installed applications.
- `ProgramData` may contain persistence mechanisms or application data used during investigations.
