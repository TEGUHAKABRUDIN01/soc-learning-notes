# Windows Event Viewer

## Overview

Windows Event Viewer is a built-in Windows tool used to view and manage event logs generated by the operating system, hardware, applications, and security components.

These logs help administrators monitor system activity, troubleshoot problems, and review important events that occur on the computer.

---

## Windows Log Categories

### 1. System

Contains events related to the Windows operating system and hardware components.

**Examples:**

- Driver events
- System startup and shutdown
- Hardware errors

---

### 2. Application

Contains events generated by applications installed on the computer.

**Examples:**

- Application errors
- Application crashes
- Application warnings

---

### 3. Setup

Contains events generated during Windows installation, updates, and system setup.

**Examples:**

- Windows installation
- Feature updates
- Windows Update events

---

### 4. Security

Contains security-related events recorded by Windows auditing.

**Examples:**

- User logon and logoff
- Account creation
- Password changes
- Security policy changes

---

### 5. Forwarded Events

Stores events that have been forwarded from other computers using Windows Event Forwarding (WEF).

---

## Event Information

Each event log contains important information that helps identify and understand what happened.

### Event ID

A unique identification number assigned to each event.

---

### Date and Time

Shows when the event occurred.

---

### Source

Identifies the application, service, driver, or system component that generated the event.

---

### Log Name

Indicates the log category where the event is stored.

Examples:

- System
- Application
- Security
- Setup
- Forwarded Events

---

### Computer

Displays the name of the computer where the event occurred.

---

## Event Severity Levels

### Information

Indicates normal system operations or successful activities.

---

### Warning

Indicates a potential issue that may require attention but does not immediately affect system operation.

---

### Error

Indicates a problem that has occurred and may affect the operation of an application, service, or system component.

---

### Critical

Indicates a serious problem that requires immediate attention because it may significantly impact system stability or availability.

---

## Opening Event Viewer

### Method 1: Run Dialog

Press **Windows + R**, then type:

```text
eventvwr.msc
```

Click **OK** or press **Enter**.

---

### Method 2: Windows Logs

After opening Event Viewer, navigate to:

```text
Windows Logs
```

The following log categories are available:

- Application
- Security
- Setup
- System
- Forwarded Events

---
